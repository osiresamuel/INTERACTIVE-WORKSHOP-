## Features

- Controlled inputs (text, email, tel, date, number, url, select)
- Validation with specific errors beside each field
- Valid registrations appear instantly; form clears with a success message
- Add with the spread operator, remove with `filter()`
- Extension feature: `<describe your feature>`

## Setup

Requires [Node.js](https://nodejs.org/).

```bash
npm install
npm run dev
```

Open the address Vite prints (usually http://localhost:5173).
